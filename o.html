O: Open/Closed Principle

El Principio Abierto/Cerrado indica que las entidades de software (clases, módulos, funciones) deben estar abiertas para su extensión pero cerradas para su modificación. Es decir, se debe poder agregar nuevo comportamiento sin alterar el código ya probado y en funcionamiento.

Esto se logra mediante abstracciones, interfaces y polimorfismo. Por ejemplo, en lugar de un if/else gigante para calcular descuentos, se define una interfaz Descuento y se crean nuevas implementaciones cuando aparecen nuevas reglas.
